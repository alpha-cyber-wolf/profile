# Alpha Cyber Wolf

Cybersecurity, digital forensics, and technical training resources.

Alpha Cyber Wolf is the GitHub organization for Alpha Wolf Cyber Solutions Pvt. Ltd. This space is for public tools, research, workflows, and educational material.

## Focus areas

- Digital forensics and incident response (DFIR)
- Forensic workflows and utilities
- Open-source intelligence (OSINT)
- Cybersecurity training and documentation
